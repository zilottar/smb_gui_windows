# SMB GUI Client

## Описание
Базовый графический клиент SMB для Windows 10/11, написанный на Python и Tkinter. Клиент предоставляет окно авторизации и окно просмотра файлов выбранного шаринга.

## Возможности
- Подключение к SMB-шаре по IP-адресу или DNS-имени.
- Настройка имени сервера, домена/рабочей группы и порта.
- Просмотр списка файлов и папок с возможностью навигации по вложенным директориям.
- Простое информирование о выборе файлов и обработка ошибок подключения.
- Скачивание выбранных файлов на локальный диск.

## Установка
1. Убедитесь, что на системе установлен Python 3.9 или новее.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## Запуск
Запустите приложение командой:
```bash
python main.py
```

После запуска появится окно авторизации. Введите параметры подключения (сервер, share, учетные данные), нажмите «Подключиться» и при успешном входе откроется окно с содержимым каталога. Для скачивания файла выделите его в списке и нажмите кнопку «Скачать…» или дважды щёлкните по имени файла.
